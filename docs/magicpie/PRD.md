# Magic Pie 黑白笔记适配 PRD

版本：1.0 · 2026-09-15 · 状态：实施基线

## 1. 背景与产品目标

Magicpie M1 的黑白墨水屏无法可靠地区分彩色工具状态和笔迹。以开源 Butterfly 2.5.5 为基础，提供可保存、可在电脑继续编辑的黑白手写笔记体验，保留上游无限画布、文件格式与存储能力。

目标仓库：https://github.com/kkkdkk/Butterfly 。这是已有公开仓库，默认分支 develop；本次使用 magicpie-monochrome 集成分支，不覆盖已有 develop 历史。

用户已同意：先 PRD、后详细 Plan；可分派多个 Sol、使用项目内 worktree，由主 agent 最终合并。现有平板测试笔记无需备份或迁移，不要求保留，但不因此执行无必要的删除。

## 2. 设备与事实边界

- 已连接设备：Magicpie M1，device=px30_eink_magicpie，Android 8.1 / API 27，armeabi-v7a。
- 上游官方 Butterfly 2.5.5 legacy ARM APK 曾成功打开画布；定制版本须重新验证。
- Wacom 压感输入与厂商 EPD API 仅为既往调查线索，不代表本次已实现刷新加速。
- Butterfly 代码采用 AGPL-3.0；保留 LICENSE、品牌素材的 BRANDING_LICENSE 和上游署名。定制版标明非官方 Magic Pie 适配。

## 3. 本期范围（M1）

### FR-01 设备限定

在 Magicpie M1 / px30_eink_magicpie 上自动启用黑白显示；其他设备和电脑保持上游行为。平台识别失败应安全回退，不阻止启动。模式不写入文档，不修改上游全局用户偏好。测试可控制识别结果。

### FR-02 黑白高对比界面

主要交互界面使用白底、黑字和无彩色强调。选中、未选中、禁用、错误状态通过黑白反转、轮廓、文字或图标区分，不仅依赖颜色。覆盖主页、编辑器工具栏、属性面板、常用对话框。原版 logo 和用户内容不作为全局滤色对象。

### FR-03 简化颜色操作

Magic Pie 隐藏绘图颜色调色板、滴管和属性颜色选择器；保留线宽、橡皮、撤销/重做及原有非颜色操作。窄屏/竖屏布局不能因移除颜色控件而溢出。非 Magic Pie 控件保持原样。

### FR-04 显示与数据分离

自由笔迹的彩色前景在设备上以黑色显示；透明度保留，纯白笔迹保留其语义。前景文字/矢量描边与填充采用一致且可读的策略。必要的画布背景和网格显示策略必须显式定义、测试，不能导致白笔或黑字在同色背景消失。不要用笼罩整棵 widget 的 ColorFiltered 改写用户图片/PDF，也不要为黑白模式增加每帧全屏离屏滤镜。

纸张对比度按背景颜色叠加（包含 alpha，底色为白）确定：浅色纸显示白底，非白笔迹显示黑色；深色纸显示黑底，前景显示白色。该规则同样应用于不绘制背景的笔迹缓存及落笔预览。原始白色保留，透明度不变。图片/PDF/SVG 内部像素不采样、不改色，其局部对比冲突不在本期自动解决。

存量半透明标记保留 alpha，不猜测不透明黄色一定是高亮；不承诺所有特殊彩色素材在黑白屏上保持原有视觉区分。冲突场景在验收报告中明确记录。

### FR-05 笔迹生命周期一致

落笔预览、抬笔后缓存、撤销/重做、缩放/平移、重新打开文件的显示一致。屏幕缓存不得泄漏到彩色导出。选择框、控制点和工具预览在黑白模式下可辨认。

### FR-06 文件与跨端兼容

保留 .bfly / .tbfly 数据结构和文档内原始颜色值；不引入定制文件格式。图片/PDF 导入资产不得被破坏性转换。PNG/SVG/PDF 等导出应使用原始文档颜色，不复用已黑白化的屏幕位图。电脑端继续使用上游 Butterfly 编辑；以自动化文件/渲染测试证明兼容，实际跨端打开另行记录实测状态。

保留已有 WebDAV/Nextcloud 入口；本期不新建云服务、不配置用户凭据、不宣称未经测试的跨端同步已经成功。用户暂无同步服务参数，这不阻止 M1 本地文件交付。

### FR-07 可安装与可回退

产出适配 API 27、ARMv7、legacy native-library packaging 的 APK。推荐独立 magicpie flavor / applicationId，便于与上游对比且避免签名冲突；无需迁移现有笔记。提供可复现命令、APK SHA256、源码 commit、已知限制。不得提交签名私钥、SDK 缓存、设备日志中的隐私数据。

## 4. 非目标与后续阶段

- M1 不实现厂商原生笔迹/EPD A2 刷新，不拷贝闭源原厂笔记模块，不宣称达到原厂延迟。
- M2：调查公开/可合法调用的 android.yitoa.px30.EinkRefreshUtil，在普通应用 UID 下做独立最小验证，确认权限、可恢复性、局部刷新与残影后再设计接入。若需要 root、系统签名或刷机，停止并请求新的授权。
- 不重构上游编辑器、不升级依赖大版本、不添加新的云同步、OCR 或账号系统。
